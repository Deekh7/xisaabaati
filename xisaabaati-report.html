نقاط القوة
ما يعمل بشكل ممتاز
  • توطين ممتاز: 3 لغات (الصومالية كلغة أساسية + العربية + الإنجليزية) مع دعم RTL كامل
  • طرق دفع محلية (EVC Plus, Zaad, Sahal) — لا يوجد Stripe أو PayPal لأنهما لا يعملان في الصومال
  • حساب الربح الفوري عند إدخال بيانات المنتج — ميزة ذكية تعلّم التاجر عن هامشه فوراً
  • ربط المنتج بالمبيعة تلقائياً يسرّع العملية ويقلل الأخطاء
  • واجهة نظيفة وحديثة لا تُرهق المستخدم — مناسبة للتجار غير التقنيين
  • عزل البيانات بين الحسابات يعمل بشكل صحيح (Firebase Firestore per-user)
  • الخطة المجانية مُجزية: المبيعات + المنتجات + العملاء + لوحة التحكم الكاملة
  • دعم متعدد المستخدمين في خطة Pro ($2.5/مستخدم) — مناسب لمحلات بها موظفين
  • تصميم متجاوب يعمل على الهاتف والحاسوب
  • أنواع النشاط (دكان، مطعم، صيدلية، خدمات) تعكس فهماً جيداً لطبيعة المستخدمين
⚠️
نقاط الضعف والملاحظات
مجالات تحتاج تحسيناً
  • قفل المصروفات والتقارير على الخطة المجانية — هذان العنصران أساسيان لأي تاجر جاد، وحجبهما يُقلل من قيمة الخطة المجانية
  • الدفع يدوي وليس آلياً — المستخدم يدفع وينتظر تأكيداً من الإدارة، مما يُشكل عائقاً في تجربة الترقية
  • تناقض الأسعار — الصفحة الرئيسية تذكر أسعاراً مختلفة عما يظهر داخل التطبيق (Basic $12 / Pro $25 في التطبيق)
  • اسم المستخدم لا يظهر في الإعدادات — حساب tester1 يُظهر "—" بدلاً من الاسم في قسم الملف الشخصي
  • لا يوجد تحقق من البريد الإلكتروني — يمكن التسجيل بأي بريد إلكتروني دون التحقق منه
  • لا توجد ميزة الفاتورة/الإيصال في الخطة المجانية — التجار يحتاجون إرسال إيصال للزبون
  • لا يوجد نسخ احتياطي أو تصدير للبيانات — لم تظهر أي إمكانية لتصدير البيانات إلى Excel أو PDF
  • 🚨 خلل حرج: Backend API معطوب في الإنتاج — جميع نقاط API على xisaabaati.vercel.app لا تستجيب (timeout)، مما يُعطّل لوحة الإدارة الكاملة وعملية قبول المدفوعات

🚨 خلل حرج: الـ Backend API معطوب كلياً في الإنتاج

جميع تبويبات لوحة الإدارة تعرض مؤشر تحميل دوار ولا تُظهر بيانات أبداً. بعد التحقيق التقني التفصيلي، تبيّن أن:

  • طلبات API تتجه إلى https://xisaabaati.vercel.app — وتظل في حالة pending إلى الأبد
  • حتى نقطة الصحة /health لا تستجيب بعد 10 ثوانٍ (timeout كامل)
  • الدالة serverless المُغلّفة لـ Express في /api/index.js تتجمّد عند التهيئة
  • السبب الأرجح: متغير البيئة FIREBASE_SERVICE_ACCOUNT غير مضبوط صحيحاً في Vercel Production، مما يجعل Firebase Admin SDK يتجمّد عند التهيئة ويمنع الاستجابة لأي طلب

التأثير: لوحة الإدارة كاملة غير صالحة للاستخدام · نظام قبول/رفض المدفوعات معطوب · لا يمكن للأدمن إدارة المستخدمين

الحل المقترح: التحقق من إعدادات Environment Variables في Vercel Dashboard → Project Settings → Environment Variables → التأكد من وجود FIREBASE_SERVICE_ACCOUNT كـ JSON سليم، أو FIREBASE_PROJECT_ID + FIREBASE_PRIVATE_KEY + FIREBASE_CLIENT_EMAIL بشكل منفصل.

التقييم النهائي: متوافق مع فكرة المشروع بقوة

xisaabaati.com يُجسّد فكرة المشروع بشكل ناجح جداً. يُقدم نظام محاسبة بسيطاً وعملياً للتجار الصغار في الصومال وشرق أفريقيا، مع توطين ممتاز للغة والعملة وطرق الدفع. الميزات الأساسية (المبيعات، المنتجات، العملاء) متاحة مجاناً وتعمل بشكل موثوق. التطبيق جاهز للاستخدام الفعلي ويحقق الهدف المُعلن: "اعرف ربحك في ثواني".

⚠ تحذير عاجل: لوحة الإدارة (Maamulka) ونظام قبول المدفوعات معطوبان بالكامل في الإنتاج بسبب عطل في الـ Backend API. يجب إصلاحه قبل استقبال أي مدفوعات حقيقية.
